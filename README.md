# Sistema de Tickets
Proyecto

Un sistema web desarrollado para la gestión, seguimiento y administración de tickets de soporte técnico e incidencias.

## Equipo del desarrollo

- Cristofer Mesta
- Joel Medrano

### Descripción del Proyecto

El objetivo de este proyecto es desarrollar una plataforma centralizada que permita a los usuarios reportar problemas o solicitudes de soporte, mientras que los administradores o técnicos pueden asignar, dar seguimiento y resolver dichos tickets de forma eficiente.
